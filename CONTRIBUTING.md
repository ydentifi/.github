# Contributing

These repositories hold released versions of Ydentifi's SDKs. Development happens in Ydentifi's own repository, so
pull requests and issues are not open here.

- Security reports: [security@ydentifi.io](mailto:security@ydentifi.io). See [SECURITY.md](SECURITY.md).
- Everything else: [ydentifi.io](https://ydentifi.io).
